Pipeline de Dados Epidemiológicos  DataSUS

Sobre o projeto

Este projeto foi desenvolvido com o objetivo de construir um pipeline de dados voltado para análise epidemiológica e acompanhamento de vacinação no Distrito Federal, utilizando dados públicos disponibilizados pelo DataSUS.

O principal desafio do projeto foi lidar com arquivos CSV altamente inconsistentes, contendo:

cabeçalhos despadronizados
linhas irrelevantes misturadas aos dados
diferentes estruturas entre arquivos
colunas desalinhadas
informações extras fora da tabela principal

O pipeline foi desenvolvido para automatizar a leitura, limpeza, transformação e disponibilização dos dados para análise.

Objetivos
Automatizar a ingestão de dados públicos
Tratar e padronizar arquivos inconsistentes
Transformar os dados em formato analítico
Disponibilizar os dados no Google BigQuery
Criar base estruturada para dashboards e análises
